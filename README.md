# CHEAT CODES:

## IN BOARD:
Ctrl [1,2,3,4]: Increase the respective player’s position on the board by 1 tile.

Alt [1,2,3,4]: Decrease the respective player’s position on the board by 1 tile.

S: Saves game state.

L: Load a saved game state.

Alt+O: Skip to next player’s turn.

ALT+T: Turns on/off turns.

Alt+U: Toggles tile overlap check(the check to see if two players share the same tile).

Alt+E: Restarts the room.

Alt+U: Restarts the game.


## IN RPS BATTLE:
-Ctrl up+ctrl down increase/decrease player 1's health.

-Alt up+alt down increase/decrease player 2's health/

-Ctrl left+Ctrl Right decrease/increase AI's lowest response time.

-Alt left+Alt Right decrease/increase AI's highest response time.
